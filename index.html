Custom formulas
Formula must return true/false. Supported variables: close, open, high, low, volume, rsi, ema9, ema21, macd, signal, vwap, sma20 and their previous-candle versions ending in Prev. Operators: > < >= <= == != && || + - * / ( ).
Example formulas
rsi > 50 && rsi > rsiPrev
ema9 > ema21
close > sma20 && volume > volumePrev
